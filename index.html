The two-machine studio

One machine to make, one to run everything. The render node is the part that changes the economics.

The render node

AMD Ryzen AI Max+ 395 · 128GB unified
  • 128GB holds large video + language models at once
  • LTX 2.3 video on the Radeon iGPU (Apache 2.0)
  • Local LLM in the unified pool — no cloud tokens
  • ComfyUI · Blender + TRIPOINT · markerless mocap
  • "Killed the $200/month AI bill" — the everyday cost moves here, once

The studio

Mac — M4 minimum (M1/8GB won't carry it)
  • Editing, color, sound, delivery
  • LMC COMMAND hub + agent orchestration
  • Client work and review
  • Drives the render node over the LAN
