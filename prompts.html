Eight prompts that turn everything in the shared ChatGPT thread — Leo's project files, reviews, notes — into the seed data for LMC COMMAND. Copy each one, paste it into the thread, save the output under the filename shown, and hand the files back. That's the whole job.

How to run them

  1. Open the shared ChatGPT thread that already holds Leo's project files (construction, cabinetry review, lighting review, TV show, studio…).
  2. Press Copy prompt on block 0, paste it in, send. Wait for ChatGPT to confirm.
  3. Do the same for 1 through 7, in order, one at a time. Let each finish before the next. If ChatGPT asks a clarifying question, answer it — completeness beats speed.
  4. Save each answer as a file with the exact filename shown on the block (CSV blocks → .csv, narrative → .md). In ChatGPT, use the copy icon on the code block, paste into a blank TextEdit/Notes file, and save with that name.
  5. Hand back: drop lmc_projects_tasks.csv and lmc_ideas_followups.csv straight into the board (Import / export, signed in) — they load as-is. Send all seven files to Work Official by text or email.
